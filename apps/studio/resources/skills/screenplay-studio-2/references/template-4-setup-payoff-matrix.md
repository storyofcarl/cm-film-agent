## SETUP & PAYOFF CODE SYSTEM

### Setup Categories
- **PS**: Plot Setup - Elements that establish plot developments
- **CS**: Character Setup - Elements that establish character traits or development
- **TS**: Thematic Setup - Elements that establish thematic ideas
- **GS**: Genre-Specific Setup - Elements specific to genre expectations

### Setup Scale
- **Major Setups**: Cross multiple sequences, significant impact on story
- **Minor Setups**: Sequence-level impact, moderate story significance
- **Micro Setups**: Scene-level impact, localized significance

### Status Tracking
- **Active**: Setup introduced but not yet paid off
- **In Progress**: Setup partially paid off
- **Paid**: Setup completely paid off
- **Abandoned**: Setup intentionally left unpaid (use sparingly)

## SETUP/PAYOFF DISTRIBUTION GUIDELINES

For balanced narrative satisfaction, aim for:

### Quantity Distribution
- 3-4 major setups per act
- 5-8 minor setups per act
- 10-15 micro setups per act

### Act Distribution
- **Act I**: 20% of total payoffs (mostly micro, few minor)
- **Act II-A**: 30% of total payoffs (mix of micro and minor)
- **Act II-B**: 30% of total payoffs (mix of minor and major)
- **Act III**: 20% of total payoffs (remaining minor and all major)

### Category Balance
Maintain a balanced mix across categories:
- 30-40% Plot setups/payoffs
- 30-40% Character setups/payoffs
- 10-20% Thematic setups/payoffs
- 10-20% Genre-specific setups/payoffs

## IMPLEMENTATION NOTES

### Effective Setups
1. Should be noticeable enough to be remembered
2. Should not be so obvious that they telegraph the payoff
3. Most effective when reinforced 1-2 times before payoff
4. Major setups should have multiple reinforcement points

### Successful Payoffs
1. Should feel both surprising and inevitable
2. Should reward audience attention and recall
3. More emotionally resonant when properly built up
4. Most satisfying when connected to character motivation

### Management Tips
1. Track in real-time as screenplay is developed
2. Review matrix after each chunk completion
3. Color-code status for visual clarity (Active = Red, Paid = Green)
4. Check for orphaned setups before finalizing screenplay
