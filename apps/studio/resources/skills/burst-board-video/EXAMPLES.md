# Burst Board Video — Worked Examples

Only the numbered shot lines are in Chinese. Everything else — structural labels, location slug, cast line, style reference, shot-type tags, dialogue inside quotes — stays in English.

---

## Example 1: Per-scene mode — one file bundling multiple bursts

Source: a trailer script with 16 scenes. User asks for bursts on all scenes. Output is 3 files. Below is a shortened preview of `RoachMotel_Bursts_Scenes01-05.md` showing the first two bursts in full.

## Example 2: Whole-piece mode — one burst, one file

Source: 3-minute music video concept covering multiple locations.

### File: `LegendOfTheSnowman_Burst.md`

```
THE LEGEND OF THE SNOWMAN — Full Burst

[PROMPT]
Total Duration: 5 Seconds
Structure: 20 Shots (Rapid Fire)
Cast: Snowman (emerald green suit, black shades, gold watch, black-and-white loafers).
Style reference: Cinematic live-action music video, photorealistic, anamorphic 35mm feel, deep emerald greens and icy cyan highlights against warm Vegas neon and sun-bleached desert, shallow depth of field, volumetric lighting, Michael Mann meets Hype Williams mafioso aesthetic.
Prompt Set: Safe Mode (Chinese Visuals + English Audio)

[1] WIDE：雪覆亚特兰大街道夜景，钠灯下呼气成雾，停放轿车结霜。
[2] INSERT：结冰的手递出乔治亚州驾照，指尖挂冰凌，另一只手伸来接过。
[3] CU：Snowman 戴墨镜，胡须结霜，嘴角浅笑 — SNOWMAN: "Welcome to Vegas, baby."
[4] MS：Snowman 手心向上，冰球成型悬空，冷蓝光映脸。
[5] OVERHEAD：沙漠双车道公路，白色老爷车与黑色皮卡并排停靠，两个小身影站其间。
[6] MS：Snowman 倚靠白色老爷车车身，雪茄在手，风吹翻领。
[7] WIDE：白色老爷车行驶沙漠公路黄昏，热浪扭曲路面。
[8] MS：Snowman 坐在 "Welcome to Fabulous Las Vegas" 路牌前老爷车敞开车门内，掌心轻抚车身。
[9] LOW ANGLE：Snowman 乐福鞋踏上龟裂沥青，维加斯霓虹虚焦于后。

[12] WIDE：赌场内景大厅，水晶吊灯辉煌，Snowman 穿行人群中央，前方地面铺白霜。
```
